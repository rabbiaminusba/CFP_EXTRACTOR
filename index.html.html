How it works: open-source OCR (Tesseract.js) running in your browser — no API key, no cost. Each page is cleaned first (handwriting, yellow and grey highlights removed), then every number is cross-checked with the CFP's own arithmetic (fuel plan adds up, Ramp = Min Dispatch + Tankering, TOW = ZFW + Ramp − Taxi, LWT = TOW − Trip, PL = ZFW − DOW). FL is always the 3rd row of the Fuel Correction table and Fuel Burn is its 1TON value. Actual Fuel is read from the blue handwriting and is always marked • for a quick visual check. Any other value the tool is unsure about is marked too. Every cell is editable — click a cell to correct it.
